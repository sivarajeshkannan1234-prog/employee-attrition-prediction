# Employee Attrition Analysis and Prediction

## Project Overview
This project analyzes employee attrition data and uses machine learning to predict employee attrition.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Streamlit

## Project Features
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Logistic Regression and Random Forest models
- Model evaluation and comparison
- Interactive Streamlit dashboard

## How to Run

1. Install the required packages:
   `pip install -r requirements.txt`
2. Run the dashboard:
   `streamlit run app.py`

## Disclaimer
Predictions are estimates for educational demonstration and should not be used as the sole basis for employment decisions.
